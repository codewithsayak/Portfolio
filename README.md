# Code With Sayak - Developer Portfolio

A premium, modern, and production-ready personal developer portfolio built entirely with HTML5, CSS3, and Vanilla JavaScript. 

No frameworks. No build systems. Just clean, optimized code.

## 🚀 Features

- **Dynamic Data Configuration:** Easily edit all content (Projects, Skills, Services, Timeline) from a single configuration object in `script.js`.
- **Dark/Light Theme:** Built-in theme switcher with `localStorage` memory and system preference detection.
- **Project Filtering & Search:** Real-time vanilla JavaScript category filtering and text search.
- **Project Detail Modal:** Accessible modal dialog showing larger details.
- **Scroll Reveal Animations:** Powered by highly performant `IntersectionObserver`.
- **Fully Responsive:** Fluid typography (`clamp()`) and custom grid/flexbox layouts.
- **Static Form Fallback:** Ready-to-go `mailto:` integration for the contact form.
